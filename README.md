# L2ClientDat Editor - Lunara Edition

L2ClientDat — редактор файлов Lineage II
L2ClientDat — программа для просмотра и редактирования файлов данных клиента Lineage II. Она помогает распаковывать файлы, изменять их содержимое и сохранять результат в нужном формате.

## Основные возможности

- открытие и редактирование файлов .dat, .ini, .txt и .htm;
- распаковка и упаковка файлов с выбором структуры хроник и параметров шифрования;
- пакетная обработка файлов и повторное шифрование;
- поиск и замена текста, работа с несколькими файлами во вкладках;
- сохранение рабочей сессии и восстановление открытых вкладок;
- переключение интерфейса между русским и английским;
- проверка и установка обновлений программы.
Программа предназначена для удобной работы с данными клиента Lineage II.

## Recommended software

- Liberica JDK 24
- Eclipse IDE for Java Developers
